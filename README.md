# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

给剧场灯光师使用的灯位与 Cue 表管理前端项目，维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和 Cue 触发顺序，包含舞台平面灯位图、Cue 列表、当前场景预览、灯具筛选和演出版本备注；并实现**色片领用闭环**，适合排练期间快速调整。

## 色片领用闭环

- **领用登记**：每个 Cue 登记所需色片型号与数量（可多行、重复行自动合并），并按其演出时间窗口（开始–结束）占用库存。
- **整次排演原子提交**：排演单可一次登记多个 Cue，提交时统一校验，任一不通过即**整次排演失败**，原 Cue 顺序、灯位图和库存保持不变（草稿保留供修改）：
  1. 同一色片被时间窗口重叠的两个 Cue 重复领用（物理色片不可同时出现在两处）；
  2. 按时间轴扫描，任一时段对某色片的叠加领用需求超过库存（提示具体时段、需求量与缺口）；
  3. 时间窗口非法（结束不晚于开始）、数量非正、色片型号不存在等结构问题。
- **取消 Cue 退库**：逐行登记拆封情况——未拆封色片全退；已拆封只退余料（折合张数），差额记为损耗并核销库存；退库与损耗写入闭环台账。取消只删除该 Cue，其余 Cue 的触发顺序不变。
- **色片筛选**：按灯位类型（面光/侧光/逆光/效果光）与色片型号筛选灯位图。
- **场景预览**：点击 Cue 列表载入当前场景，灯位图高亮上场灯具，预览面板按主色调与亮度模拟舞台效果。
- **本地存储同步**：演出信息、灯具、库存、Cue、台账、草稿、筛选与预览选择均写入 localStorage，刷新后保留；可一键恢复初始数据。

## 技术栈

React 19 + Vite 7 + TypeScript（strict），无后端，数据持久化使用浏览器 localStorage。
