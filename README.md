# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

做一个给剧场灯光师使用的灯位与Cue表管理前端项目，可以维护演出名称、灯具编号、通道号、色片、焦点位置、亮度预设和Cue触发顺序。页面需要有舞台平面灯位图、Cue列表、当前场景预览、灯具筛选和演出版本备注，适合排练期间快速调整。

## 技术栈

React + Vite + TypeScript

## 功能

- 灯位图与场景预览：舞台平面灯位图按灯具类型筛选，点击 Cue 即按色片颜色与亮度预设预览场景
- Cue 表维护：触发顺序上下调整、新增 Cue（灯具、通道、焦点、亮度、时间窗口、色片型号与数量）
- 色片领用闭环：
  - 「开始排演」整次校验——同一色片被时间窗口重叠的 Cue 重复领用，或任一时段需求超过可用库存，则整次排演失败，Cue 顺序、灯位图与库存均不变
  - 校验通过才按各 Cue 时间窗口领用并占用库存；排演中新增 Cue 可「重新校验并补领」
  - 取消 Cue / 结束排演时结算退还：未拆封色片全退，已拆封只退余料，差额自动记入损耗记录
- 色片时段占用图：按时间轴展示每种色片的占用窗口，重叠与超库存红色预警
- 本地持久化：Cue 表、库存、损耗记录、排演状态、色片/灯具筛选与当前场景预览均写入 localStorage，刷新后保留
